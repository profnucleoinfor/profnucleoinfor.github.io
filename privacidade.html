Privacidade

Como seus dados são usados

Este portal foi criado para apoiar alunos da NIC Formação Profissional. As informações preenchidas no acesso do aluno ficam salvas no próprio navegador do dispositivo, usando armazenamento local.

Dados salvos no navegador

O portal pode guardar nome do aluno, dia da aula e horário da aula para facilitar o acesso ao painel. Esses dados não são enviados para um banco de dados por este site estático.

Uso de links externos

Alguns botões podem abrir serviços externos, como WhatsApp, LinkedIn, fontes e bibliotecas visuais. Esses serviços possuem suas próprias políticas de privacidade.

Aplicativo e cache

Para funcionar melhor como aplicativo, o site pode salvar arquivos no cache do navegador. Isso ajuda a carregar páginas com mais rapidez e melhora a experiência em celulares.

Como apagar os dados

Na área do aluno, o botão de sair limpa os dados salvos pelo portal. Também é possível apagar os dados diretamente nas configurações do navegador.
